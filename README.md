# دفتر الصندوق

تطبيق ويب بسيط لإدارة دفتر الصندوق اليومي لمستخدم واحد.

يحفظ الحركات في **Supabase / PostgreSQL** بشكل دائم. لا يستخدم LocalStorage لتخزين البيانات المالية.

## المتطلبات

- Node.js 18 أو أحدث
- مشروع [Supabase](https://supabase.com)

## الإعداد

### 1. تثبيت الحزم

```bash
npm install
```

### 2. إنشاء جدول قاعدة البيانات

في لوحة Supabase:

1. افتح **SQL Editor**
2. أنشئ استعلاماً جديداً
3. انسخ محتوى الملف `supabase/schema.sql`
4. نفّذ الاستعلام

الجدول الرئيسي: `cash_entries`

### 3. إعداد المتغيرات

انسخ ملف البيئة:

```bash
copy .env.example .env
```

ثم ضع قيم مشروعك:

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

تجد القيم في Supabase من:

**Project Settings → API**

### 4. تشغيل التطبيق

```bash
npm run dev
```

افتح الرابط الذي يظهر في الطرفية، عادة:

http://localhost:5173

## الاستخدام

- عند الفتح تظهر صفحة **اليوم** تلقائياً
- أضف حركة وارد أو صادر
- تنقّل بين الأيام أو اختر تاريخاً من التقويم
- الرصيد الحالي يُحسب من **جميع** الحركات
- الرصيد التراكمي يُحسب زمنياً حسب `date` ثم `created_at`
- الملخص الشهري يعرض إجمالي الوارد والصادر وصافي الحركة
